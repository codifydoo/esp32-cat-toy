# Cat Toy M0–M3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take the Waveshare ESP32-S3-Touch-AMOLED-1.75 from unboxed to a toy she can play with: a cat-hosted carousel menu, six app slots (five simple placeholder cat screens), and a working Silly voices app.

**Architecture:** ESP-IDF firmware split into small components:

| Component | Role |
| --- | --- |
| `logic` | Pure C, host-tested |
| `assets` | LittleFS image and sound loading |
| `platform` | Hardware services |
| `cat` | The cat widget |
| `ui` | Menu, app manager, idle, apps |

Images are generated from the Claude Design SVG geometry by a Node exporter, and sounds by a sox/Python pipeline. Both are packed into a LittleFS partition.

**Tech Stack:** ESP-IDF v5.5.5 (C11), LVGL 9.4, Waveshare BSP 3.0.1 (esp_lvgl_adapter, esp_codec_dev), QMI8658, joltwallet/littlefs, CMake + Unity (host tests), Node 26 + @resvg/resvg-js + pngjs, Python 3 + sox.

**Spec:** `docs/superpowers/specs/2026-09-22-cat-toy-design.md` (UI source of truth: `design/claude-design/`)

## Global Constraints

- **ESP-IDF v5.5.5**, target `esp32s3`. Every `idf.py`, `cmake`, `python` and `tools/*.sh` command runs in a shell that has sourced `~/esp/esp-idf/export.sh`. This puts ESP-IDF's Python, which has pyserial, on `PATH`.
- **Managed components:**
  - `waveshare/esp32_s3_touch_amoled_1_75` `^3.0.1`
  - `lvgl/lvgl` `9.4.*`
  - `waveshare/qmi8658` `^2.0.1`
  - `joltwallet/littlefs` `^1.22.3`
- **Audio format everywhere:** 24000 Hz, 16-bit signed, mono (`AUDIO_RATE_HZ`).
- **Image format:** LVGL v9 `.bin`, RGB565A8. The 12-byte header has magic `0x19` and cf `0x14`, followed by the RGB565 plane, then the A8 plane. Images are loaded into PSRAM.
- **Assets:** the partition label is `assets`, mounted read-only at `/assets`. Images are at `/assets/img/<name>.bin` and sounds at `/assets/snd/<name>.wav`.
- **Cat scales:** S = 0.65, M = 1.0, L = 1.3 of the design's 200 × 210 cat. The export canvas is the viewBox `-20 -20 240 250`.
- **No child-facing text:** nothing she sees contains text. Labels appear only on developer screens (diag, gallery).
- **Volume:** the cap defaults to 60 % and is hard-capped at 80 % (`SETTINGS_VOLUME_MAX`).
- **Recordings** live only in RAM (PSRAM) and are freed when played or discarded.
- **LVGL access:** LVGL objects are touched only on the LVGL task or while holding `display_lock()`. Brightness changes happen only on the LVGL task.
- **Adding an app** = one new file in `components/ui/apps/` plus one `X(app_name)` line in `APP_LIST` (`components/ui/apps/registry.c`).
- **Host tests:** `test/run.sh` must pass before any commit that touches `components/logic/`.
- **Commits:** `feat:`, `fix:`, `test:`, `chore:`, `docs:` prefixes, with no attribution trailers.
- **Human steps** are marked **Human step**. The executing agent asks the user to do them and waits for the answer. Never guess a result that needs eyes or hands on the board.

## Review Focus

These are the five cases most likely to hurt her in use that no host unit test exercises. Each has a pinned device check in the owning task:

1. **Home pressed while recording or playing** in Silly voices must stop audio, free buffers, and land on the menu with no crash and no late callback touching deleted objects. Pinned in Task 17, Step 7, and by the soak test in Task 18.
2. **Rapid or overlapping touches** (double-tapping the icon, swiping during a swipe, tapping during the open zoom) must never open two apps or leave the menu stuck. Pinned in Task 15, Step 8.
3. **A silent recording** (she taps the mic and says nothing) returns to idle with a meow instead of playing silence. **A very loud one** plays without wrap-around distortion. Pinned in Task 17, Step 7, plus saturation tests in Task 7.
4. **A missing or bad asset** (a file not generated, the wrong WAV format) shows the magenta placeholder or stays silent, with a log line and no crash. Pinned in Task 10, Step 5, and Task 12, Step 5.
5. **Button edge cases:** held during boot, contact bounce, and Power pressed inside an app. The next touch only wakes the screen and doesn't trigger an app action. Pinned in Task 5 (debounce tests) and Task 16, Step 6.

```c
#include <dirent.h>
#include "bsp/esp-bsp.h"
#include "esp_heap_caps.h"
#include "esp_littlefs.h"
#include "esp_log.h"
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "lvgl.h"

static const char *TAG = "main";

void app_main(void)
{
    esp_vfs_littlefs_conf_t conf = {
        .base_path = "/assets",
        .partition_label = "assets",
        .read_only = true,
    };
    ESP_ERROR_CHECK(esp_vfs_littlefs_register(&conf));

    bsp_display_start();
    bsp_display_lock(-1);
    lv_obj_t *scr = lv_screen_active();
    lv_obj_set_style_bg_color(scr, lv_color_black(), 0);
    lv_obj_t *dot = lv_obj_create(scr);
    lv_obj_set_size(dot, 200, 200);
    lv_obj_center(dot);
    lv_obj_set_style_radius(dot, LV_RADIUS_CIRCLE, 0);
    lv_obj_set_style_border_width(dot, 0, 0);
    lv_obj_set_style_bg_color(dot, lv_color_hex(0xFF9F43), 0);
    bsp_display_unlock();

    for (;;) {
        DIR *dir = opendir("/assets");
        struct dirent *e;
        while (dir && (e = readdir(dir)) != NULL) {
            ESP_LOGI(TAG, "asset: %s", e->d_name);
        }
        if (dir) {
            closedir(dir);
        }
        ESP_LOGI(TAG, "psram free: %u", (unsigned)heap_caps_get_free_size(MALLOC_CAP_SPIRAM));
        vTaskDelay(pdMS_TO_TICKS(2000));
    }
}
```

`tools/serial_log.py`:
```python
#!/usr/bin/env python3
"""Print the board's serial output for N seconds (a non-interactive idf.py monitor)."""
import sys
import time

import serial


def open_port(port, deadline):
    while True:
        try:
            return serial.Serial(port, 115200, timeout=0.2)
        except serial.SerialException:
            if time.time() > deadline:
                raise
            time.sleep(0.2)


def main():
    port = sys.argv[1]
    seconds = float(sys.argv[2]) if len(sys.argv) > 2 else 10.0
    end = time.time() + seconds
    with open_port(port, time.time() + 5) as s:
        while time.time() < end:
            data = s.read(4096)
            if data:
                sys.stdout.write(data.decode("utf-8", "replace"))
                sys.stdout.flush()


if __name__ == "__main__":
    main()
```

`components/logic/include/gestures.h`:
```c
#pragma once
#include <stdbool.h>
#include <stdint.h>

#define GESTURE_TAP_MAX_PX   20
#define GESTURE_SWIPE_MIN_PX 60
#define GESTURE_SWIPE_MAX_MS 400u
/* A swipe also needs |dx| >= 1.5 * |dy| (compared as 2|dx| >= 3|dy|). */

typedef enum {
    GESTURE_NONE = 0,
    GESTURE_TAP,
    GESTURE_SWIPE_LEFT,
    GESTURE_SWIPE_RIGHT,
} gesture_kind_t;

typedef struct {
    bool active;
    int16_t x0, y0;
    uint32_t t0_ms;
    uint32_t max_dist2; /* farthest squared distance from the start point */
```

```c
#include <stdlib.h>

void gesture_begin(gesture_track_t *g, int16_t x, int16_t y, uint32_t t_ms)
{
    g->active = true;
    g->x0 = x;
    g->y0 = y;
    g->t0_ms = t_ms;
    g->max_dist2 = 0;
}

static void track(gesture_track_t *g, int16_t x, int16_t y)
{
    int32_t dx = x - g->x0;
    int32_t dy = y - g->y0;
    uint32_t d2 = (uint32_t)(dx * dx + dy * dy);
    if (d2 > g->max_dist2) {
        g->max_dist2 = d2;
    }
}

void gesture_move(gesture_track_t *g, int16_t x, int16_t y)
{
    if (g->active) {
        track(g, x, y);
    }
}

gesture_kind_t gesture_end(gesture_track_t *g, int16_t x, int16_t y, uint32_t t_ms)
{
    if (!g->active) {
        return GESTURE_NONE;
    }
    g->active = false;
    track(g, x, y);
    if (g->max_dist2 <= (uint32_t)(GESTURE_TAP_MAX_PX * GESTURE_TAP_MAX_PX)) {
        return GESTURE_TAP;
    }
    int32_t dx = x - g->x0;
    int32_t dy = y - g->y0;
    int32_t adx = abs(dx);
    int32_t ady = abs(dy);
    if (adx >= GESTURE_SWIPE_MIN_PX && 2 * adx >= 3 * ady && t_ms - g->t0_ms <= GESTURE_SWIPE_MAX_MS) {
        return dx < 0 ? GESTURE_SWIPE_LEFT : GESTURE_SWIPE_RIGHT;
    }
    return GESTURE_NONE;
```

```c
#include "carousel.h"

void carousel_init(carousel_t *c, uint8_t count)
{
    c->count = count ? count : 1;
    c->index = 0;
}

uint8_t carousel_step(carousel_t *c, int8_t dir)
{
    if (dir > 0) {
        c->index = (uint8_t)((c->index + 1) % c->count);
    } else if (dir < 0) {
        c->index = (uint8_t)((c->index + c->count - 1) % c->count);
    }
    return c->index;
}

dot_window_t carousel_dot_window(const carousel_t *c)
{
    dot_window_t w = {.first = 0, .n = c->count};
    if (c->count > CAROUSEL_MAX_DOTS) {
        int first = (int)c->index - CAROUSEL_MAX_DOTS / 2;
        int max_first = c->count - CAROUSEL_MAX_DOTS;
        if (first < 0) {
            first = 0;
        }
        if (first > max_first) {
            first = max_first;
        }
        w.first = (uint8_t)first;
        w.n = CAROUSEL_MAX_DOTS;
    }
    return w;
}

dot_kind_t carousel_dot_kind(const carousel_t *c, uint8_t i)
{
    dot_window_t w = carousel_dot_window(c);
    int last = w.first + w.n - 1;
    if (i < w.first || i > last) {
        return DOT_HIDDEN;
    }
    if (i == c->index) {
        return DOT_ACTIVE;
    }
    if (c->count > CAROUSEL_MAX_DOTS && ((i == w.first && w.first > 0) || (i == last && last < c->count - 1))) {
        return DOT_EDGE;
    }
    return DOT_IDLE;
}
```

```c
{
    d->stable = pressed_now;
    d->count = 0;

bool debounce_update(debounce_t *d, bool raw_pressed)

    return d->stable;
}
```

```c
#include "envelope.h"

uint16_t envelope_peak(const int16_t *samples, size_t n)
{
    uint16_t peak = 0;
    for (size_t i = 0; i < n; i++) {
        int32_t v = samples[i];
        uint16_t a = (uint16_t)(v < 0 ? (v == INT16_MIN ? INT16_MAX : -v) : v);
        if (a > peak) {
            peak = a;
        }
    }
    return peak;
}

uint8_t envelope_mouth(uint16_t peak)
{
    if (peak < ENVELOPE_MOUTH_B_PEAK) {
        return 0;
    }
    return peak < ENVELOPE_MOUTH_C_PEAK ? 1 : 2;
}

void rec_stop_init(rec_stop_t *r)
{
    r->heard = false;
    r->quiet_samples = 0;
}

bool rec_stop_update(rec_stop_t *r, uint16_t chunk_peak, uint32_t chunk_samples, uint32_t rate_hz)
{
    if (chunk_peak >= REC_SPEECH_PEAK) {
        r->heard = true;
        r->quiet_samples = 0;
        return false;
    }
    r->quiet_samples += chunk_samples;
    return r->heard && (uint64_t)r->quiet_samples * 1000u >= (uint64_t)REC_SILENCE_STOP_MS * rate_hz;
}
```

```c
bool wav_parse(const uint8_t *buf, size_t len, wav_info_t *out)
{
    if (len < 12 || memcmp(buf, "RIFF", 4) != 0 || memcmp(buf + 8, "WAVE", 4) != 0) {
        return false;
    }
    bool have_fmt = false;
    size_t p = 12;
    while (p + 8 <= len) {
        uint32_t size = rd32(buf + p + 4);
        const uint8_t *body = buf + p + 8;
        size_t avail = len - (p + 8);
        if (memcmp(buf + p, "fmt ", 4) == 0) {
            if (size < 16 || avail < 16 || rd16(body) != 1) {
                return false;
            }
            out->channels = rd16(body + 2);
            out->rate = rd32(body + 4);
            out->bits = rd16(body + 14);
            have_fmt = true;
        } else if (memcmp(buf + p, "data", 4) == 0) {
            if (!have_fmt) {
                return false;
            }
            out->data_offset = p + 8;
            out->data_bytes = (size < avail ? size : avail) & ~(size_t)1;
            return true;
        }
        size_t step = 8 + (size_t)size + (size & 1u);
        if (step > len - p) {
            break;
        }
        p += step;
    }
    return false;
}
```

```c
#include "voice_fx.h"
#include <math.h>

#define STEP_MOUSE_Q16 98304u /* 1.5 */
#define STEP_LION_Q16  43691u /* 2/3 */
#define ROBOT_RING_HZ  30.0f
#define CAVE_REPEATS   4u

static int16_t sat16(int32_t v)
{
    return (int16_t)(v > INT16_MAX ? INT16_MAX : v < INT16_MIN ? INT16_MIN : v);
}

static size_t resample_len(size_t in_len, uint32_t step_q16)
{
    return in_len == 0 ? 0 : (size_t)((((uint64_t)(in_len - 1)) << 16) / step_q16) + 1;
}

static size_t resample(const int16_t *in, size_t in_len, int16_t *out, size_t out_cap, uint32_t step_q16)
{
    size_t total = resample_len(in_len, step_q16);
    size_t n = total < out_cap ? total : out_cap;
    for (size_t i = 0; i < n; i++) {
        uint64_t pos = (uint64_t)i * step_q16;
        size_t idx = (size_t)(pos >> 16);
        int64_t frac = (int64_t)(pos & 0xFFFFu);
        int32_t a = in[idx];
        int32_t b = idx + 1 < in_len ? in[idx + 1] : a;
        out[i] = (int16_t)(a + (int32_t)(((int64_t)(b - a) * frac) / 65536));
    }
    return n;
}

size_t voice_fx_output_len(voice_t v, size_t in_len, uint32_t rate_hz)
{
    switch (v) {
    case VOICE_MOUSE: return resample_len(in_len, STEP_MOUSE_Q16);
    case VOICE_LION: return resample_len(in_len, STEP_LION_Q16);
    case VOICE_CAVE: return in_len == 0 ? 0 : in_len + CAVE_REPEATS * (rate_hz / 4u);
    default: return in_len;
    }
}

size_t voice_fx_apply(voice_t v, const int16_t *in, size_t in_len, int16_t *out, size_t out_cap, uint32_t rate_hz)
{
    if (in_len == 0) {
        return 0;
    }
    switch (v) {
    case VOICE_MOUSE:
        return resample(in, in_len, out, out_cap, STEP_MOUSE_Q16);
    case VOICE_LION:
        return resample(in, in_len, out, out_cap, STEP_LION_Q16);
    case VOICE_ROBOT: {
        size_t n = in_len < out_cap ? in_len : out_cap;
        const float w = 2.0f * 3.14159265f * ROBOT_RING_HZ / (float)rate_hz;
        for (size_t i = 0; i < n; i += 2) {
            int32_t m = (int32_t)lrintf((float)in[i] * sinf(w * (float)i));
            int16_t q = (int16_t)((uint16_t)sat16(m) & 0xFF00u);
            out[i] = q;
            if (i + 1 < n) {
                out[i + 1] = q;
            }
        }
        return n;
    }
    case VOICE_CAVE: {
        size_t d = rate_hz / 4u;
        size_t total = voice_fx_output_len(v, in_len, rate_hz);
        size_t n = total < out_cap ? total : out_cap;
        for (size_t i = 0; i < n; i++) {
            int32_t acc = 0;
            for (size_t k = 0; k <= CAVE_REPEATS; k++) {
                size_t off = k * d;
                if (i >= off && i - off < in_len) {
                    acc += in[i - off] / (1 << k);
                }
            }
            out[i] = sat16(acc);
        }
        return n;
    }
    default:
        return 0;
    }
}
```

```c
            v = i;
        }
    }
    if (v < 0) {
        fprintf(stderr, "unknown voice %s\n", argv[1]);
        return 2;
    }
    uint32_t rate = (uint32_t)strtoul(argv[2], NULL, 10);
    FILE *f = fopen(argv[3], "rb");
    if (!f) {
        perror(argv[3]);
        return 1;
    }
    fseek(f, 0, SEEK_END);
    long bytes = ftell(f);
    fseek(f, 0, SEEK_SET);
    size_t n = (size_t)bytes / 2;
    int16_t *in = malloc(n * sizeof(int16_t) + 2);
    if (fread(in, sizeof(int16_t), n, f) != n) {
        fprintf(stderr, "short read\n");
        return 1;

    fclose(f);

    fclose(o);
```

```python
#!/usr/bin/env python3
"""Synthesize UI sounds and placeholder animal sounds as 24 kHz mono 16-bit WAV (stdlib only)."""
import math
import random
import struct
import sys
import wave

RATE = 24000
random.seed(7)


def env(i, n, attack=0.01, release=0.3):
    t, dur = i / RATE, n / RATE
    a = min(1.0, t / attack) if attack > 0 else 1.0
    r = min(1.0, (dur - t) / (release * dur)) if release > 0 else 1.0
    return max(0.0, min(a, r))


def sweep(f0, f1, dur, harmonics=(1.0,), vibrato=0.0, attack=0.01, release=0.3):
    n = int(dur * RATE)
    out, ph = [], 0.0
    for i in range(n):
        f = f0 + (f1 - f0) * i / max(1, n - 1)
        f *= 1 + vibrato * math.sin(2 * math.pi * 6 * i / RATE)
        ph += 2 * math.pi * f / RATE
        v = sum(a * math.sin(k * ph) for k, a in enumerate(harmonics, 1))
        out.append(v * env(i, n, attack, release))
    return out


def glide(points, dur, **kw):
    seg = dur / (len(points) - 1)
    out = []
    for a, b in zip(points, points[1:]):
        out += sweep(a, b, seg, **kw)
    return out


def noise(dur, lp=0.2, attack=0.01, release=0.3, am=0.0):
    n = int(dur * RATE)
    out, y = [], 0.0
    for i in range(n):
        y += lp * (random.uniform(-1, 1) - y)
        m = 1.0 if am == 0 else 0.5 + 0.5 * math.sin(2 * math.pi * am * i / RATE)
        out.append(y * m * env(i, n, attack, release))
    return out


def silence(dur):
    return [0.0] * int(dur * RATE)


def mix(a, b):
    n = max(len(a), len(b))
    return [(a[i] if i < len(a) else 0.0) + (b[i] if i < len(b) else 0.0) for i in range(n)]


def notes(freqs, each, gap=0.0, **kw):
    out = []
    for f in freqs:
        out += sweep(f, f, each, **kw) + silence(gap)
    return out


def square(f, dur):
    n = int(dur * RATE)
    return [(0.5 if math.sin(2 * math.pi * f * i / RATE) >= 0 else -0.5) * env(i, n, 0.005, 0.1) for i in range(n)]


def bursts(count, each, gap, lp):
    out = []
    for _ in range(count):
        out += noise(each, lp=lp, attack=0.002, release=0.6) + silence(gap)
    return out


def saw(f, dur, attack, release):
    n = int(dur * RATE)
    return [((i * f / RATE) % 1.0 - 0.5) * env(i, n, attack, release) for i in range(n)]


C5, E5, G5, C6, E6, G6 = 523.25, 659.25, 783.99, 1046.5, 1318.5, 1568.0
BELL = (1.0, 0.0, 0.3, 0.0, 0.15)
PURR_AM = [0.6 + 0.4 * math.sin(2 * math.pi * 28 * i / RATE) for i in range(int(0.7 * RATE))]

RECIPES = {
    "blip_up": lambda: sweep(600, 1200, 0.12),
    "blip_down": lambda: sweep(1200, 600, 0.12),
    "pop": lambda: mix(sweep(420, 180, 0.08, release=0.9), noise(0.015, lp=0.9)),
    "click": lambda: noise(0.015, lp=0.9, attack=0.001, release=0.9),
    "chime_boot": lambda: notes([C6, E6, G6], 0.14, harmonics=BELL, release=0.8),
    "chime_wake": lambda: notes([C5, E5, G5, C6], 0.18, harmonics=BELL, release=0.8),
    "sparkle": lambda: sweep(3000, 3400, 0.04, harmonics=BELL, release=0.9),
    "bell_tick": lambda: sweep(2000, 2000, 0.06, harmonics=BELL, release=0.9),
    "beep_boop": lambda: square(800, 0.12) + silence(0.04) + square(500, 0.14),
    "fanfare": lambda: notes([C5, E5, G5], 0.12, gap=0.02, harmonics=(1, 0.5, 0.25))
    + sweep(C6, C6, 0.5, harmonics=(1, 0.5, 0.25)),
    "meow": lambda: glide([520, 880, 640], 0.5, harmonics=(1, 0.6, 0.3, 0.15), vibrato=0.01, attack=0.05),
    "meow_high": lambda: glide([700, 1100, 800], 0.4, harmonics=(1, 0.6, 0.3), vibrato=0.01, attack=0.04),
```

```bash
# Build every sound in sounds.txt into assets/snd/<name>.wav (24 kHz, 16-bit, mono).
# Real recordings in assets-src/sounds/{phrases,sfx}/<name>.wav win over generated placeholders.
set -euo pipefail

HERE="$(cd "$(dirname "$0")" && pwd)"
ROOT="$(cd "$HERE/../.." && pwd)"
SRC="$ROOT/assets-src/sounds"
OUT="$ROOT/assets/snd"
TMP="$ROOT/build-assets/snd"
FXCLI="$ROOT/build-host/fxcli"
RATE=24000
PHRASE_PITCH_CENTS=400 # spec 6.2: phrases pitched up 4 semitones into the cat voice
GAP_S=0.08

[ -x "$FXCLI" ] || { echo "error: $FXCLI missing. Run test/run.sh first." >&2; exit 1; }
command -v sox >/dev/null || { echo "error: sox missing (brew install sox)" >&2; exit 1; }

rm -rf "$OUT" "$TMP"
mkdir -p "$OUT" "$TMP"
sox -n -r "$RATE" -c 1 -b 16 "$TMP/gap.wav" trim 0 "$GAP_S"

# finish <in> <out> [sox effects applied before trimming and normalizing]
finish() {
    local in="$1" out="$2"
    shift 2
    sox "$in" -r "$RATE" -c 1 -b 16 -e signed-integer "$out" "$@" \
        silence 1 0.02 0.5% reverse silence 1 0.02 0.5% reverse norm -3
}

placeholders=""

while read -r name kind spec; do
    case "$name" in '' | '#'*) continue ;; esac
    out="$OUT/$name.wav"
    case "$kind" in
    phrase)
        if [ -f "$SRC/phrases/$name.wav" ]; then
            src="$SRC/phrases/$name.wav"
        else
            src="$TMP/$name.aiff"
            say -v Lana -o "$src" "$spec"
            placeholders="$placeholders $name"
        fi
        finish "$src" "$out" pitch "$PHRASE_PITCH_CENTS"
        ;;
    synth)
        python3 "$HERE/synth.py" "$spec" "$TMP/$name.wav"
        finish "$TMP/$name.wav" "$out"
        ;;
    organic)
        if [ -f "$SRC/sfx/$name.wav" ]; then
            finish "$SRC/sfx/$name.wav" "$out"
        else
            python3 "$HERE/synth.py" "$spec" "$TMP/$name.wav"
            finish "$TMP/$name.wav" "$out"
            placeholders="$placeholders $name"
        fi
        ;;
    pitch)
        base="${spec%%:*}"
        semis="${spec##*:}"
        sox "$OUT/$base.wav" "$out" pitch $((semis * 100))
        ;;
    concat)
        parts=()
        i=0
        IFS='+' read -ra items <<<"$spec"
        for item in "${items[@]}"; do
            src="$OUT/${item%%@*}.wav"
            if [[ "$item" == *@* ]]; then
                sox "$src" -t raw -r "$RATE" -e signed-integer -b 16 -c 1 "$TMP/$name.$i.raw"
                "$FXCLI" "${item##*@}" "$RATE" "$TMP/$name.$i.raw" "$TMP/$name.$i.fx.raw"
                sox -t raw -r "$RATE" -e signed-integer -b 16 -c 1 "$TMP/$name.$i.fx.raw" "$TMP/$name.$i.wav"
                src="$TMP/$name.$i.wav"
            fi
            if [ "$i" -gt 0 ]; then
                parts+=("$TMP/gap.wav")
            fi
            parts+=("$src")
            i=$((i + 1))
        done
        sox "${parts[@]}" "$out" norm -3
        ;;
    *)
        echo "error: unknown kind '$kind' for $name" >&2
        exit 1
        ;;
    esac
    echo "  $name"
done <"$HERE/sounds.txt"

echo "Built $(ls "$OUT" | wc -l | tr -d ' ') sounds into assets/snd"
if [ -n "$placeholders" ]; then
    echo "Placeholders (replace them via docs/recording-list.md):$placeholders"
```

```js
import { Resvg } from '@resvg/resvg-js';
import { PNG } from 'pngjs';

// Render an SVG string to straight-alpha RGBA at the given pixel width.
export function render(svg, width) {
  const resvg = new Resvg(svg, { fitTo: { mode: 'width', value: width }, background: 'rgba(0, 0, 0, 0)' });
  const png = PNG.sync.read(resvg.render().asPng());
  return { w: png.width, h: png.height, rgba: png.data };
}

export function alphaBBox(img) {
  let x0 = img.w, y0 = img.h, x1 = -1, y1 = -1;
  for (let y = 0; y < img.h; y++) {
    for (let x = 0; x < img.w; x++) {
      if (img.rgba[(y * img.w + x) * 4 + 3] > 0) {
        if (x < x0) x0 = x;
        if (x > x1) x1 = x;
        if (y < y0) y0 = y;
        if (y > y1) y1 = y;
      }
    }
  }
  return x1 < 0 ? null : { x0, y0, x1, y1 };
}

export function unionBBox(a, b) {
  if (!a) return b;
  if (!b) return a;
  return { x0: Math.min(a.x0, b.x0), y0: Math.min(a.y0, b.y0), x1: Math.max(a.x1, b.x1), y1: Math.max(a.y1, b.y1) };
}

// Grow a box by one pixel where needed so width and height are even, without leaving the canvas.
export function evenBBox(bb, w, h) {
  const out = { ...bb };
  if ((out.x1 - out.x0 + 1) % 2) {
    if (out.x1 + 1 < w) out.x1 += 1;
    else if (out.x0 > 0) out.x0 -= 1;
  }
  if ((out.y1 - out.y0 + 1) % 2) {
    if (out.y1 + 1 < h) out.y1 += 1;
    else if (out.y0 > 0) out.y0 -= 1;
  }
  return out;
}

export function crop(img, bb) {
  const w = bb.x1 - bb.x0 + 1;
  const h = bb.y1 - bb.y0 + 1;
  const rgba = Buffer.alloc(w * h * 4);
  for (let y = 0; y < h; y++) {
    const start = ((bb.y0 + y) * img.w + bb.x0) * 4;
    img.rgba.copy(rgba, y * w * 4, start, start + w * 4);
  }
  return { w, h, rgba };
}

// LVGL v9 image file: 12-byte header (magic 0x19, cf RGB565A8 = 0x14), RGB565 plane, then A8 plane.
export function toLvglBin(img) {
  const { w, h, rgba } = img;
  const stride = w * 2;
  const buf = Buffer.alloc(12 + stride * h + w * h);
  buf[0] = 0x19;
  buf[1] = 0x14;
  buf.writeUInt16LE(0, 2);
  buf.writeUInt16LE(w, 4);
  buf.writeUInt16LE(h, 6);
  buf.writeUInt16LE(stride, 8);
  buf.writeUInt16LE(0, 10);
  const alpha = 12 + stride * h;
  for (let i = 0; i < w * h; i++) {
    const r = rgba[i * 4], g = rgba[i * 4 + 1], b = rgba[i * 4 + 2], a = rgba[i * 4 + 3];
    buf.writeUInt16LE(a === 0 ? 0 : ((r >> 3) << 11) | ((g >> 2) << 5) | (b >> 3), 12 + i * 2);
    buf[alpha + i] = a;
  }
  return buf;
}

export function toPng(img) {
  const png = new PNG({ width: img.w, height: img.h });
  img.rgba.copy(png.data);
  return PNG.sync.write(png);
}
```

```js
// Renders every image asset into assets/img and writes the C manifest used by the firmware.
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { CANVAS, VARIANTS, catParts } from './cat_geometry.mjs';
import { APP_ICONS, appIconSvg } from './icons.mjs';
import { UI_IMAGES } from './ui_images.mjs';
import { render, alphaBBox, unionBBox, evenBBox, crop, toLvglBin, toPng } from './raster.mjs';

const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '../..');
const IMG_OUT = path.join(ROOT, 'assets/img');
const PREVIEW = path.join(ROOT, 'build-assets/preview');
const MANIFEST_H = path.join(ROOT, 'components/assets/include/assets_manifest.h');
const MANIFEST_C = path.join(ROOT, 'components/assets/assets_manifest.c');
const SCALES = [['S', 0.65], ['M', 1.0], ['L', 1.3]];

const svgDoc = ([x, y, w, h], inner) =>
  `<svg xmlns="http://www.w3.org/2000/svg" viewBox="${x} ${y} ${w} ${h}" width="${w}" height="${h}">${inner}</svg>`;

const written = [];
function write(name, img) {
  const bin = path.join(IMG_OUT, `${name}.bin`);
  const png = path.join(PREVIEW, `${name}.png`);
  fs.mkdirSync(path.dirname(bin), { recursive: true });
  fs.mkdirSync(path.dirname(png), { recursive: true });
  fs.writeFileSync(bin, toLvglBin(img));
  fs.writeFileSync(png, toPng(img));
  written.push(name);
}

fs.rmSync(IMG_OUT, { recursive: true, force: true });
fs.rmSync(PREVIEW, { recursive: true, force: true });

// Cat parts: one crop box per (part, scale), shared by all variants so positions never differ.
const variants = Object.keys(VARIANTS);
const partsBy = Object.fromEntries(variants.map((v) => [v, catParts(VARIANTS[v])]));
const catRows = Object.keys(partsBy[variants[0]]).map((part) => ({
  part,
  shared: variants.every((v) => partsBy[v][part] === partsBy[variants[0]][part]),
  x: [],
  y: [],
}));
const canvas = [];
SCALES.forEach(([tag, scale], si) => {
  const width = Math.round(CANVAS.w * scale);
  for (const row of catRows) {
    const owners = row.shared ? ['shared'] : variants;
    const imgs = owners.map((o) =>
      render(svgDoc([CANVAS.x, CANVAS.y, CANVAS.w, CANVAS.h], partsBy[o === 'shared' ? variants[0] : o][row.part]), width),
    );
    canvas[si] = { w: imgs[0].w, h: imgs[0].h };
    let bb = imgs.map(alphaBBox).reduce((a, b) => unionBBox(a, b), null);
    if (!bb) throw new Error(`cat part ${row.part} renders empty at ${tag}`);
    bb = evenBBox(bb, imgs[0].w, imgs[0].h);
    owners.forEach((o, i) => write(`cat/${o}/${tag}/${row.part}`, crop(imgs[i], bb)));
    row.x[si] = bb.x0;
    row.y[si] = bb.y0;
  }
});

// App icons at menu size and parent-grid size.
for (const app of APP_ICONS) {
  write(`apps/${app.key}`, render(appIconSvg(app), 240));
  write(`apps/${app.key}_96`, render(appIconSvg(app), 96));
}

// UI images; cropped ones record where their top-left belongs.
const uiRows = [];
for (const u of UI_IMAGES) {
  let img = render(svgDoc(u.viewBox, u.svg), u.viewBox[2]);
  let x = 0;
  let y = 0;
  if (u.crop) {
    const bb = evenBBox(alphaBBox(img), img.w, img.h);
    img = crop(img, bb);
    x = bb.x0;
    y = bb.y0;
  }
  write(u.name, img);
  uiRows.push({ name: u.name, x, y });
}

// C manifest.
const q = (s) => JSON.stringify(s);
fs.writeFileSync(
  MANIFEST_H,
  [
    '// Generated by tools/export_images/export.mjs. Do not edit.',
    '#pragma once',
    '#include <stddef.h>',
    '#include <stdint.h>',
    '',
    'typedef struct {',
    '    const char *part;',
    '    uint8_t shared; /* 1: one image for every cat variant, under "cat/shared/" */',
    '    int16_t x[3];   /* top-left inside the rendered cat canvas, per scale S, M, L */',
    '    int16_t y[3];',
    '} cat_part_pos_t;',
    '',
    'typedef struct {',
    '    const char *name;',
    '    int16_t x;',
    '    int16_t y;',
    '} ui_image_pos_t;',
    '',
    'extern const int16_t CAT_CANVAS_W[3];',
    'extern const int16_t CAT_CANVAS_H[3];',
    'extern const int16_t CAT_ORIGIN_PX[3]; /* where the design origin (0,0) sits inside the canvas */',
    'extern const cat_part_pos_t CAT_PARTS[];',
    'extern const size_t CAT_PARTS_COUNT;',
    'extern const ui_image_pos_t UI_IMAGE_POS[];',
    'extern const size_t UI_IMAGE_POS_COUNT;',
    '',
  ].join('\n'),
);
fs.writeFileSync(
  MANIFEST_C,
  [
    '// Generated by tools/export_images/export.mjs. Do not edit.',
    '#include "assets_manifest.h"',
    '',
    `const int16_t CAT_CANVAS_W[3] = {${canvas.map((c) => c.w).join(', ')}};`,
    `const int16_t CAT_CANVAS_H[3] = {${canvas.map((c) => c.h).join(', ')}};`,
    `const int16_t CAT_ORIGIN_PX[3] = {${canvas.map((c) => Math.round((-CANVAS.x * c.w) / CANVAS.w)).join(', ')}};`,
    '',
    'const cat_part_pos_t CAT_PARTS[] = {',
    ...catRows.map((r) => `    {${q(r.part)}, ${r.shared ? 1 : 0}, {${r.x.join(', ')}}, {${r.y.join(', ')}}},`),
    '};',
    `const size_t CAT_PARTS_COUNT = ${catRows.length};`,
    '',
    'const ui_image_pos_t UI_IMAGE_POS[] = {',
    ...uiRows.map((r) => `    {${q(r.name)}, ${r.x}, ${r.y}},`),
    '};',
    `const size_t UI_IMAGE_POS_COUNT = ${uiRows.length};`,
    '',
  ].join('\n'),
);

// Contact sheet for eyeballing against design/claude-design/CatSheet.dc.html.
```

```c
#include "assets.h"
#include <stdio.h>
#include <string.h>
#include "assets_manifest.h"
#include "esp_heap_caps.h"
#include "esp_littlefs.h"
#include "esp_log.h"

#define PLACEHOLDER_PX 32

typedef struct entry {
    struct entry *next;
    char name[48];
    lv_image_dsc_t dsc;
    uint8_t *buf; /* NULL when dsc is a copy of the placeholder */
} entry_t;

static const char *TAG = "assets";
static entry_t *s_cache;
static lv_image_dsc_t s_placeholder;
static uint16_t s_placeholder_buf[PLACEHOLDER_PX * PLACEHOLDER_PX * 3 / 2]; /* RGB565 plane + A8 plane */

static void build_placeholder(void)
{
    uint8_t *alpha = (uint8_t *)s_placeholder_buf + PLACEHOLDER_PX * PLACEHOLDER_PX * 2;
    const int r = PLACEHOLDER_PX / 2;
    for (int y = 0; y < PLACEHOLDER_PX; y++) {
        for (int x = 0; x < PLACEHOLDER_PX; x++) {
            int dx = x - r, dy = y - r, i = y * PLACEHOLDER_PX + x;
            s_placeholder_buf[i] = 0xF81F; /* magenta */
            alpha[i] = dx * dx + dy * dy <= r * r ? 255 : 0;
        }
    }
    s_placeholder.header.magic = LV_IMAGE_HEADER_MAGIC;
    s_placeholder.header.cf = LV_COLOR_FORMAT_RGB565A8;
    s_placeholder.header.w = PLACEHOLDER_PX;
    s_placeholder.header.h = PLACEHOLDER_PX;
    s_placeholder.header.stride = PLACEHOLDER_PX * 2;
    s_placeholder.data = (const uint8_t *)s_placeholder_buf;
    s_placeholder.data_size = sizeof(s_placeholder_buf);
}

esp_err_t assets_init(void)
{
    build_placeholder();
    esp_vfs_littlefs_conf_t conf = {
        .base_path = ASSETS_BASE_PATH,
        .partition_label = "assets",
        .read_only = true,
    };
    esp_err_t err = esp_vfs_littlefs_register(&conf);
    if (err != ESP_OK) {
        ESP_LOGE(TAG, "mount failed: %s", esp_err_to_name(err));
    }
    return err;
}

/* Reads and validates one image file; returns the buffer (header + planes) or NULL. */
static uint8_t *read_image(const char *path, size_t *size_out)
{
    FILE *f = fopen(path, "rb");
    if (!f) {
        ESP_LOGE(TAG, "missing image %s", path);
        return NULL;
    }
    fseek(f, 0, SEEK_END);
    long size = ftell(f);
    fseek(f, 0, SEEK_SET);
    uint8_t *buf = size > (long)sizeof(lv_image_header_t) ? heap_caps_malloc((size_t)size, MALLOC_CAP_SPIRAM) : NULL;
    bool ok = buf && fread(buf, 1, (size_t)size, f) == (size_t)size;
    fclose(f);
    if (ok) {
        lv_image_header_t hdr;
        memcpy(&hdr, buf, sizeof(hdr));
        size_t need = sizeof(hdr) + (size_t)hdr.stride * hdr.h + (size_t)hdr.w * hdr.h;
        ok = hdr.magic == LV_IMAGE_HEADER_MAGIC && hdr.cf == LV_COLOR_FORMAT_RGB565A8 && (size_t)size >= need;
    }
    if (!ok) {
        ESP_LOGE(TAG, "bad image %s", path);
        heap_caps_free(buf);
        return NULL;
    }
    *size_out = (size_t)size;
    return buf;
}

const lv_image_dsc_t *assets_image(const char *name)
{
    for (entry_t *e = s_cache; e; e = e->next) {
        if (strcmp(e->name, name) == 0) {
            return &e->dsc;
        }
    }
    entry_t *e = heap_caps_calloc(1, sizeof(entry_t), MALLOC_CAP_SPIRAM);
    if (!e) {
        return &s_placeholder;
    }
    strlcpy(e->name, name, sizeof(e->name));
    char path[96];
    snprintf(path, sizeof(path), ASSETS_BASE_PATH "/img/%s.bin", name);
    size_t size = 0;
    e->buf = read_image(path, &size);
    if (e->buf) {
        memcpy(&e->dsc.header, e->buf, sizeof(lv_image_header_t));
        e->dsc.data = e->buf + sizeof(lv_image_header_t);
        e->dsc.data_size = (uint32_t)(size - sizeof(lv_image_header_t));
    } else {
        e->dsc = s_placeholder; /* cached so the error is logged once, not every frame */
    }
    e->next = s_cache;
    s_cache = e;
    return &e->dsc;
}

void assets_ui_pos(const char *name, int16_t *x, int16_t *y)
{
    *x = 0;
    *y = 0;
    for (size_t i = 0; i < UI_IMAGE_POS_COUNT; i++) {
        if (strcmp(UI_IMAGE_POS[i].name, name) == 0) {
            *x = UI_IMAGE_POS[i].x;
            *y = UI_IMAGE_POS[i].y;
            return;
        }
    }
}
```

```c
static uint8_t s_variant;

{
    esp_err_t err = nvs_flash_init();
    if (err != ESP_OK) {
        ESP_LOGW(TAG, "NVS unusable (%s); erasing and using defaults", esp_err_to_name(err));
        ESP_RETURN_ON_ERROR(nvs_flash_erase(), TAG, "erase");
        ESP_RETURN_ON_ERROR(nvs_flash_init(), TAG, "init after erase");
    }
    ESP_RETURN_ON_ERROR(nvs_open("cat", NVS_READWRITE, &s_nvs), TAG, "open");
    nvs_get_u8(s_nvs, "vol", &s_volume); /* NOT_FOUND leaves the default in place */

    nvs_get_u32(s_nvs, "hidden", &s_hidden);

        s_variant = 0;
    }
    ESP_LOGI(TAG, "volume cap %u%%, cat %u, hidden apps 0x%08lx", s_volume, s_variant, (unsigned long)s_hidden);
    return ESP_OK;
}

    }
}
```

```c
#include "buttons.h"
#include <stdbool.h>
#include "bsp/esp-bsp.h"
#include "debounce.h"
#include "driver/gpio.h"
#include "esp_check.h"
#include "esp_io_expander.h"

#define HOME_GPIO GPIO_NUM_0            /* BOOT button, low while pressed */
#define POWER_PIN IO_EXPANDER_PIN_NUM_4 /* TCA9554 EXIO4 = SYS_OUT, high while PWR is pressed */

static const char *TAG = "buttons";
static esp_io_expander_handle_t s_expander;
static debounce_t s_home, s_power;

static bool home_raw(void) { return gpio_get_level(HOME_GPIO) == 0; }

static bool power_raw(void)
{
    uint32_t levels = 0;
    if (!s_expander || esp_io_expander_get_level(s_expander, POWER_PIN, &levels) != ESP_OK) {
        return false;
    }
    return (levels & POWER_PIN) != 0;
}

esp_err_t buttons_init(void)
{
    const gpio_config_t io = {
        .pin_bit_mask = 1ULL << HOME_GPIO,
        .mode = GPIO_MODE_INPUT,
        .pull_up_en = GPIO_PULLUP_ENABLE,
    };
    ESP_RETURN_ON_ERROR(gpio_config(&io), TAG, "BOOT gpio");
    s_expander = bsp_io_expander_init();
    if (s_expander) {
        esp_io_expander_set_dir(s_expander, POWER_PIN, IO_EXPANDER_INPUT);
    } else {
        ESP_LOGW(TAG, "IO expander missing; PWR button disabled");
    }
    debounce_init(&s_home, home_raw());
    debounce_init(&s_power, power_raw());
    return ESP_OK;
}

uint8_t buttons_poll(void)
{
    uint8_t ev = 0;
    if (debounce_update(&s_home, home_raw())) {
        ev |= BUTTON_EV_HOME;
    }
    if (debounce_update(&s_power, power_raw())) {
        ev |= BUTTON_EV_POWER;
    }
    return ev;
}
```

- Produces:
  ```c

  typedef struct {
      void (*on_recorded)(uint32_t session, int16_t *pcm, size_t n, bool heard); /* callee owns pcm: heap_caps_free() it */
      void (*on_level)(uint32_t session, uint16_t peak);                         /* every 20 ms while a session clip plays */
      void (*on_done)(uint32_t session);                                         /* session clip ended or was replaced */
  } audio_listener_t;
  esp_err_t audio_init(uint8_t volume_pct);
  bool audio_available(void);
  void audio_set_volume(uint8_t pct);                 /* clamped to SETTINGS_VOLUME_MAX */
  void audio_play(sound_id_t id);                     /* one-shot fx channel; replaces what plays */
  void audio_loop_start(sound_id_t id);
  void audio_loop_stop(void);
  void audio_stop_all(void);
  uint32_t audio_session_begin(const audio_listener_t *listener); /* new session replaces the old one */
  void audio_session_end(uint32_t session);            /* no callbacks for it after this returns */
  void audio_record_start(uint32_t session, size_t max_samples);
  void audio_record_stop(uint32_t session);            /* ends early and delivers on_recorded */
  void audio_play_pcm(uint32_t session, int16_t *pcm, size_t n); /* takes ownership of pcm */
  ```

**Rules:**
- All public functions are non-blocking. They queue a command, and callbacks run on the audio task (core 0).
- A callback that touches LVGL must take `display_lock()` and re-check its session under the lock.
- A stale session's commands free their buffers and do nothing else.

- [ ] **Step 2: Write `components/platform/audio.c`**

```c
#include "audio.h"
#include <stdio.h>
#include <string.h>
#include "bsp/esp-bsp.h"
#include "envelope.h"
#include "esp_check.h"
#include "esp_codec_dev.h"
#include "esp_heap_caps.h"
#include "freertos/FreeRTOS.h"
#include "freertos/queue.h"
#include "freertos/task.h"
#include "settings.h"
#include "wav.h"

#define CHUNK_SAMPLES      480 /* 20 ms at 24 kHz */
#define MIC_GAIN_DB        30.0f
#define AUDIO_MIC_CHANNELS 1   /* set to 2 if recordings are silent (see Task 13, Step 6) */

static const char *TAG = "audio";

typedef enum {
    CMD_PLAY,
    CMD_PLAY_PCM,
    CMD_LOOP_START,
    CMD_LOOP_STOP,
    CMD_STOP_ALL,
    CMD_REC_START,
    CMD_REC_STOP,
    CMD_SESSION_END,
    CMD_VOLUME,
} cmd_kind_t;

typedef struct {
    cmd_kind_t kind;
    uint32_t session;
    uint32_t arg;
    int16_t *pcm;
    size_t n;
} cmd_t;

typedef struct {
    int16_t *pcm;
    size_t n;
    bool tried;
} clip_t;

static esp_codec_dev_handle_t s_spk, s_mic;
static QueueHandle_t s_queue;
static bool s_ok;
static portMUX_TYPE s_mux = portMUX_INITIALIZER_UNLOCKED;
static uint32_t s_session;
static uint32_t s_next_session = 1;
static audio_listener_t s_listener;
static clip_t s_clips[SND_COUNT];

/* Audio-task-only state. */
static const int16_t *s_fx;
static int16_t *s_fx_owned;
static size_t s_fx_n, s_fx_pos;
static uint32_t s_fx_session;
static const int16_t *s_loop;
static size_t s_loop_n, s_loop_pos;
static int16_t *s_rec;
static size_t s_rec_n, s_rec_max;
static uint32_t s_rec_session;
static rec_stop_t s_rec_stop;

static int16_t clamp16(int32_t v) { return (int16_t)(v > INT16_MAX ? INT16_MAX : v < INT16_MIN ? INT16_MIN : v); }

static uint32_t current_session(void)
{
    portENTER_CRITICAL(&s_mux);
    uint32_t s = s_session;
    portEXIT_CRITICAL(&s_mux);
    return s;
}

static bool listener_for(uint32_t session, audio_listener_t *out)
{
    portENTER_CRITICAL(&s_mux);
    bool ok = session != 0 && session == s_session;
    if (ok) {
        *out = s_listener;
    }
    portEXIT_CRITICAL(&s_mux);
    return ok;
}

static const clip_t *clip_get(uint32_t id)
{
    if (id >= SND_COUNT) {
        return NULL;
    }
    clip_t *c = &s_clips[id];
    if (c->pcm || c->tried) {
        return c->pcm ? c : NULL;
    }
    c->tried = true; /* a missing or bad file is reported once, then stays silent */
    char path[64];
    if (!sounds_path((sound_id_t)id, path, sizeof(path))) {
        return NULL;
    }
    FILE *f = fopen(path, "rb");
    if (!f) {
        ESP_LOGE(TAG, "missing sound %s", path);
        return NULL;
    }
    fseek(f, 0, SEEK_END);
    long len = ftell(f);
    fseek(f, 0, SEEK_SET);
    uint8_t *buf = len > 44 ? heap_caps_malloc((size_t)len, MALLOC_CAP_SPIRAM) : NULL;
    bool ok = buf && fread(buf, 1, (size_t)len, f) == (size_t)len;
    fclose(f);
    wav_info_t w;
    if (!ok || !wav_parse(buf, (size_t)len, &w) || w.channels != 1 || w.bits != 16 || w.rate != AUDIO_RATE_HZ) {
        ESP_LOGE(TAG, "bad sound %s (need 24 kHz 16-bit mono PCM)", path);
        heap_caps_free(buf);
        return NULL;
    }
    memmove(buf, buf + w.data_offset, w.data_bytes);
    c->pcm = (int16_t *)buf;
    c->n = w.data_bytes / 2;
    return c;
}

static void fx_finish(bool notify)
{
    uint32_t session = s_fx_session;
    heap_caps_free(s_fx_owned);
    s_fx = NULL;
    s_fx_owned = NULL;
    s_fx_n = s_fx_pos = 0;
    s_fx_session = 0;
    audio_listener_t l;
    if (notify && session && listener_for(session, &l) && l.on_done) {
        l.on_done(session);
    }
}

static void rec_finish(void)
{
    int16_t *buf = s_rec;
    size_t n = s_rec_n;
    uint32_t session = s_rec_session;
    bool heard = s_rec_stop.heard;
    s_rec = NULL;
    s_rec_n = 0;
    s_rec_session = 0;
    audio_listener_t l;
    if (listener_for(session, &l) && l.on_recorded) {
        l.on_recorded(session, buf, n, heard);
    } else {
        heap_caps_free(buf);
    }
}

static void handle(const cmd_t *c)
{
    switch (c->kind) {
    case CMD_PLAY: {
        const clip_t *clip = clip_get(c->arg);
        if (clip && !s_rec) {
            fx_finish(true);
            s_fx = clip->pcm;
            s_fx_n = clip->n;
        }
        break;
    }
    case CMD_PLAY_PCM:
        if (c->session != current_session() || s_rec) {
            heap_caps_free(c->pcm);
            break;
        }
        fx_finish(true);
        s_fx = s_fx_owned = c->pcm;
        s_fx_n = c->n;
        s_fx_session = c->session;
        break;
    case CMD_LOOP_START: {
        const clip_t *clip = clip_get(c->arg);
        if (clip) {
            s_loop = clip->pcm;
            s_loop_n = clip->n;
            s_loop_pos = 0;
        }
        break;
    }
    case CMD_LOOP_STOP:
        s_loop = NULL;
        break;
    case CMD_STOP_ALL:
        fx_finish(true);
        s_loop = NULL;
        break;
    case CMD_REC_START:
        if (c->session != current_session() || s_rec) {
            break;
        }
        fx_finish(true);
        s_loop = NULL;
        s_rec = heap_caps_malloc(c->n * sizeof(int16_t), MALLOC_CAP_SPIRAM);
        s_rec_max = c->n;
        s_rec_n = 0;
        s_rec_session = c->session;
        rec_stop_init(&s_rec_stop);
        if (!s_rec) {
            ESP_LOGE(TAG, "no memory for a %u-sample recording", (unsigned)c->n);
            rec_finish(); /* delivers pcm = NULL, n = 0 */
        }
        break;
    case CMD_REC_STOP:
        if (s_rec && c->session == s_rec_session) {
            rec_finish();
        }
        break;
    case CMD_SESSION_END:
        if (s_rec && s_rec_session == c->session) {
            heap_caps_free(s_rec);
            s_rec = NULL;
            s_rec_n = 0;
            s_rec_session = 0;
        }
        if (s_fx_session == c->session) {
            fx_finish(false);
        }
        break;
    case CMD_VOLUME:
        esp_codec_dev_set_out_vol(s_spk, (int)c->arg);
        break;
    }
}

static void record_chunk(void)
{
    size_t want = s_rec_max - s_rec_n;
    if (want > CHUNK_SAMPLES) {
        want = CHUNK_SAMPLES;
    }
    int16_t *dst = s_rec + s_rec_n;
#if AUDIO_MIC_CHANNELS == 2
    static int16_t stereo[CHUNK_SAMPLES * 2];
    if (esp_codec_dev_read(s_mic, stereo, (int)(want * 4)) != ESP_CODEC_DEV_OK) {
        rec_finish();
        return;
    }
    for (size_t i = 0; i < want; i++) {
        dst[i] = stereo[i * 2];
    }
#else
    if (esp_codec_dev_read(s_mic, dst, (int)(want * 2)) != ESP_CODEC_DEV_OK) {
        rec_finish();
        return;
    }
#endif
    uint16_t peak = envelope_peak(dst, want);
    s_rec_n += want;
    if (rec_stop_update(&s_rec_stop, peak, (uint32_t)want, AUDIO_RATE_HZ) || s_rec_n >= s_rec_max) {
        rec_finish();
    }
}

static void play_chunk(void)
{
    static int16_t mix[CHUNK_SAMPLES];
    for (size_t i = 0; i < CHUNK_SAMPLES; i++) {
        int32_t v = 0;
        if (s_fx && s_fx_pos < s_fx_n) {
            v += s_fx[s_fx_pos++];
        }
        if (s_loop) {
            v += s_loop[s_loop_pos++];
            if (s_loop_pos >= s_loop_n) {
                s_loop_pos = 0;
            }
        }
        mix[i] = clamp16(v);
    }
    esp_codec_dev_write(s_spk, mix, sizeof(mix));
    if (s_fx) {
        audio_listener_t l;
        if (s_fx_session && listener_for(s_fx_session, &l) && l.on_level) {
            l.on_level(s_fx_session, envelope_peak(mix, CHUNK_SAMPLES));
        }
        if (s_fx_pos >= s_fx_n) {
            fx_finish(true);
        }
    }
}

static void audio_task(void *arg)
{
    (void)arg;
    cmd_t c;
    for (;;) {
        bool busy = s_fx || s_loop || s_rec;
        if (xQueueReceive(s_queue, &c, busy ? 0 : portMAX_DELAY) == pdTRUE) {
            handle(&c);
            continue; /* drain every queued command before the next chunk */
        }
        if (s_rec) {
            record_chunk();
        } else if (s_fx || s_loop) {
            play_chunk();
        }
    }
}

static void send(cmd_t c)
{
    if (!s_ok || xQueueSend(s_queue, &c, 0) != pdTRUE) {
        if (s_ok) {
            ESP_LOGW(TAG, "command queue full; dropped command %d", c.kind);
        }
        if (c.kind == CMD_PLAY_PCM) {
            heap_caps_free(c.pcm);
        }
    }
}

static uint8_t clamp_volume(uint8_t pct) { return pct > SETTINGS_VOLUME_MAX ? SETTINGS_VOLUME_MAX : pct; }

esp_err_t audio_init(uint8_t volume_pct)
{
    s_spk = bsp_audio_codec_speaker_init();
    s_mic = bsp_audio_codec_microphone_init();
    ESP_RETURN_ON_FALSE(s_spk && s_mic, ESP_FAIL, TAG, "codec init failed");
    esp_codec_dev_sample_info_t fs = {
        .bits_per_sample = 16,
        .channel = 1,
        .sample_rate = AUDIO_RATE_HZ,
    };
    ESP_RETURN_ON_FALSE(esp_codec_dev_open(s_spk, &fs) == ESP_CODEC_DEV_OK, ESP_FAIL, TAG, "speaker open failed");
    fs.channel = AUDIO_MIC_CHANNELS;
    ESP_RETURN_ON_FALSE(esp_codec_dev_open(s_mic, &fs) == ESP_CODEC_DEV_OK, ESP_FAIL, TAG, "mic open failed");
    esp_codec_dev_set_in_gain(s_mic, MIC_GAIN_DB);
    esp_codec_dev_set_out_vol(s_spk, clamp_volume(volume_pct));
    s_queue = xQueueCreate(16, sizeof(cmd_t));
    ESP_RETURN_ON_FALSE(s_queue, ESP_ERR_NO_MEM, TAG, "queue");
    ESP_RETURN_ON_FALSE(xTaskCreatePinnedToCore(audio_task, "audio", 6144, NULL, 5, NULL, 0) == pdPASS, ESP_ERR_NO_MEM,
                        TAG, "task");
    s_ok = true;
    ESP_LOGI(TAG, "ready: %d Hz mono, volume %u%%", AUDIO_RATE_HZ, clamp_volume(volume_pct));
    return ESP_OK;
}

bool audio_available(void) { return s_ok; }
void audio_set_volume(uint8_t pct) { send((cmd_t){.kind = CMD_VOLUME, .arg = clamp_volume(pct)}); }
void audio_play(sound_id_t id) { send((cmd_t){.kind = CMD_PLAY, .arg = (uint32_t)id}); }
void audio_loop_start(sound_id_t id) { send((cmd_t){.kind = CMD_LOOP_START, .arg = (uint32_t)id}); }
void audio_loop_stop(void) { send((cmd_t){.kind = CMD_LOOP_STOP}); }
void audio_stop_all(void) { send((cmd_t){.kind = CMD_STOP_ALL}); }

uint32_t audio_session_begin(const audio_listener_t *listener)
{
    portENTER_CRITICAL(&s_mux);
    uint32_t s = s_next_session++;
    if (s_next_session == 0) {
        s_next_session = 1;
    }
    s_session = s;
    s_listener = *listener;
    portEXIT_CRITICAL(&s_mux);
    return s;
}

void audio_session_end(uint32_t session)
{
    if (session == 0) {
        return;
    }
    portENTER_CRITICAL(&s_mux);
    if (s_session == session) {
        s_session = 0;
    }
    portEXIT_CRITICAL(&s_mux);
    send((cmd_t){.kind = CMD_SESSION_END, .session = session});
}

void audio_record_start(uint32_t session, size_t max_samples)
{
    send((cmd_t){.kind = CMD_REC_START, .session = session, .n = max_samples});
}

void audio_record_stop(uint32_t session) { send((cmd_t){.kind = CMD_REC_STOP, .session = session}); }

void audio_play_pcm(uint32_t session, int16_t *pcm, size_t n)
{
    send((cmd_t){.kind = CMD_PLAY_PCM, .session = session, .pcm = pcm, .n = n});
}
```

```c
static const char *TAG = "imu";
static qmi8658_dev_t s_dev;

esp_err_t imu_init(void)

    ESP_RETURN_ON_ERROR(qmi8658_set_accel_range(&s_dev, QMI8658_ACCEL_RANGE_4G), TAG, "range");
    ESP_RETURN_ON_ERROR(qmi8658_set_accel_odr(&s_dev, QMI8658_ACCEL_ODR_125HZ), TAG, "rate");
    ESP_RETURN_ON_ERROR(qmi8658_enable_accel(&s_dev, true), TAG, "enable");
    s_ok = true;
    return ESP_OK;
}

bool imu_read_g(float *x, float *y, float *z)
{
    float mx, my, mz;
    if (!s_ok || qmi8658_read_accel_mg(&s_dev, &mx, &my, &mz) != ESP_OK) {
        return false;
    }
    *x = mx / 1000.0f;
    *y = my / 1000.0f;
    *z = mz / 1000.0f;
    return true;
}
```

```c
{
```

```c
    const uint32_t t = c->tick;

    place(c, L_MANE, c->costume == CAT_COSTUME_LION ? MANE_PART[talking ? (t / 3) % 2 : 0] : NULL, 0, 0);
    place(c, L_TAIL, TAIL_PART[(t / 2) % 4], 0, 0);
    place(c, L_BODY, "body", 0, 0);
    bool own_ears = c->costume == CAT_COSTUME_NONE || c->costume == CAT_COSTUME_MINER;
    place(c, L_EARS, own_ears ? EARS_PART[e->ears] : NULL, 0, 0);
    place(c, L_COSTUME_EARS,
          c->costume == CAT_COSTUME_MOUSE ? "mouse_ears" : c->costume == CAT_COSTUME_LION ? "lion_ears" : NULL, 0, 0);
    place(c, L_HEAD, "head", 0, 0);
    place(c, L_BLUSH, e->blush ? "blush" : NULL, 0, 0);

    const char *eyes;
    bool pupils = false;
    switch (e->eyes) {
    case EYES_OPEN:
        eyes = BLINK_PART[c->blink];
        pupils = c->blink == 0;
        break;
    case EYES_HAPPY: eyes = "eyes_happy"; break;
    case EYES_BIG: eyes = "eyes_big"; break;
    case EYES_HALF: eyes = "eyes_half"; break;
    case EYES_CLOSED: eyes = "eyes_closed"; break;
    default: eyes = SPIRAL_PART[t % 4]; break;
    }
    place(c, L_EYES, eyes, 0, 0);
    float lx = c->look_set ? c->look_x : e->look_x10 / 10.0f;
    float ly = c->look_set ? c->look_y : e->look_y10 / 10.0f;
    int16_t ox = sc(c, lx * LOOK_RANGE), oy = sc(c, ly * LOOK_RANGE), gap = sc(c, EYE_SPACING);
    place(c, L_PUPIL_L, pupils ? "pupil" : NULL, ox, oy);
    place(c, L_PUPIL_R, pupils ? "pupil" : NULL, (int16_t)(gap + ox), oy);
    place(c, L_HL_L, pupils ? "highlight" : NULL, ox, oy);
    place(c, L_HL_R, pupils ? "highlight" : NULL, (int16_t)(gap + ox), oy);

    const char *mouth = e->mouth;
    if (talking) {
        if (lv_tick_elaps(c->talk_ext_ms) > TALK_HOLD_MS) {
            c->talk_frame = TALK_SEQ[(t / 2) % 4];
        }
        mouth = TALK_PART[c->talk_frame];
    } else if (c->state == CAT_EATING) {
        mouth = (t / 2) % 2 ? "mouth_smallw" : "mouth_munch";
    }
    place(c, L_MOUTH, mouth, 0, 0);
    place(c, L_PROP, e->fx == FX_FISH ? "prop_fish" : e->fx == FX_BROOM ? "prop_broom" : NULL, 0, 0);

    const int16_t *pp = PAW_POS[e->paws];
    place(c, L_PAW_A, "paw", sc(c, pp[0] - PAW_DRAWN_X), sc(c, pp[1] - PAW_DRAWN_Y));
    place(c, L_PAW_B, "paw", sc(c, pp[2] - PAW_DRAWN_X), sc(c, pp[3] - PAW_DRAWN_Y));
    place(c, L_HELMET,
          c->costume == CAT_COSTUME_ROBOT   ? ROBOT_PART[(t / 6) % 2]
          : c->costume == CAT_COSTUME_MINER ? MINER_PART[(t / 6) % 2]
                                            : NULL,
          0, 0);

    const char *fx = NULL;
    switch (e->fx) {
    case FX_WAVES: fx = "fx_waves"; break;
    case FX_Z1: fx = "fx_zz_f0"; break;
    case FX_ZZ: fx = ZZ_PART[(t / 4) % 2]; break;
    case FX_STARS: fx = "fx_stars"; break;
    case FX_SPARKLES: fx = (t / 3) % 2 ? "fx_sparkles" : NULL; break;
    case FX_PURR: fx = PURR_PART[(t / 2) % 2]; break;
    case FX_NOTE: fx = "fx_note"; break;
    case FX_SHH: fx = "fx_shh"; break;
    default: break;
    }
    place(c, L_FX, fx, 0, 0);

    bool calm = c->state == CAT_SLEEPING || c->state == CAT_SLEEPY || c->state == CAT_SHH;
    lv_obj_set_style_translate_y(c->rig, calm ? 0 : sc(c, BOB[(t / 2) % 6]), 0);
    lv_obj_set_style_transform_rotation(c->rig, c->state == CAT_DIZZY ? ((t / 4) % 2 ? DIZZY_ROTATION : -DIZZY_ROTATION) : 0, 0);
}

static void on_timer(lv_timer_t *timer)
{
    cat_t *c = lv_timer_get_user_data(timer);
    c->tick++;
    if (c->blink) {
        c->blink = (uint8_t)((c->blink + 1) % 4);
    } else if (c->tick >= c->next_blink) {
        c->blink = 1;
        c->next_blink = c->tick + 36 + esp_random() % 37; /* every 3 to 6 s */
    }
    apply(c);
}

static void on_delete(lv_event_t *e)
{
    cat_t *c = lv_event_get_user_data(e);
    lv_timer_delete(c->timer);
    lv_free(c);
}

static cat_t *get(lv_obj_t *obj) { return (cat_t *)lv_obj_get_user_data(obj); }

void cat_set_variant(cat_variant_t variant) { s_variant = variant < CAT_VARIANT_COUNT ? variant : CAT_VARIANT_ORANGE; }

lv_obj_t *cat_create(lv_obj_t *parent, cat_scale_t scale)
{
    cat_t *c = lv_malloc_zeroed(sizeof(cat_t));
    LV_ASSERT_MALLOC(c);
    c->scale = scale;
    c->state = CAT_HAPPY;
    c->next_blink = 40;
    const int32_t w = CAT_CANVAS_W[scale], h = CAT_CANVAS_H[scale];

    c->root = lv_obj_create(parent);
    lv_obj_remove_style_all(c->root);
    lv_obj_set_size(c->root, w, h);
    lv_obj_remove_flag(c->root, LV_OBJ_FLAG_CLICKABLE | LV_OBJ_FLAG_SCROLLABLE);

    c->rig = lv_obj_create(c->root);
    lv_obj_remove_style_all(c->rig);
    lv_obj_set_size(c->rig, w, h);
    lv_obj_remove_flag(c->rig, LV_OBJ_FLAG_CLICKABLE | LV_OBJ_FLAG_SCROLLABLE);
    lv_obj_set_style_transform_pivot_x(c->rig, w / 2, 0);
    lv_obj_set_style_transform_pivot_y(c->rig, h / 2, 0);

    for (int l = 0; l < L_COUNT; l++) {
        c->img[l] = lv_image_create(c->rig);
        lv_obj_remove_flag(c->img[l], LV_OBJ_FLAG_CLICKABLE);
        lv_obj_add_flag(c->img[l], LV_OBJ_FLAG_HIDDEN);
    }
    lv_obj_set_user_data(c->root, c);
    lv_obj_add_event_cb(c->root, on_delete, LV_EVENT_DELETE, c);
    apply(c);
    c->timer = lv_timer_create(on_timer, FRAME_MS, c);
    return c->root;
}

void cat_set_origin(lv_obj_t *cat, int32_t x, int32_t y)
{
    cat_t *c = get(cat);
    lv_obj_set_pos(cat, x - CAT_ORIGIN_PX[c->scale], y - CAT_ORIGIN_PX[c->scale]);
}

void cat_set_state(lv_obj_t *cat, cat_state_t state)
{
    cat_t *c = get(cat);
    c->state = state < CAT_STATE_COUNT ? state : CAT_HAPPY;
    c->look_set = false;
    apply(c);
}

void cat_set_costume(lv_obj_t *cat, cat_costume_t costume)
{
    cat_t *c = get(cat);
    c->costume = costume < CAT_COSTUME_COUNT ? costume : CAT_COSTUME_NONE;
    apply(c);
}

void cat_set_look(lv_obj_t *cat, float x, float y)
{
    cat_t *c = get(cat);
    c->look_x = x < -1 ? -1 : x > 1 ? 1 : x;
    c->look_y = y < -1 ? -1 : y > 1 ? 1 : y;
    c->look_set = true;
    apply(c);
}

void cat_set_mouth(lv_obj_t *cat, uint8_t frame)
{
    cat_t *c = get(cat);
    c->talk_frame = frame > 2 ? 2 : frame;
    c->talk_ext_ms = lv_tick_get();
    apply(c);
}

const char *cat_state_name(cat_state_t state) { return state < CAT_STATE_COUNT ? STATE_NAME[state] : "?"; }
```

```c
#include "launcher.h"
#include <math.h>
#include <stdbool.h>
#include "app.h"
#include "app_manager.h"
#include "assets.h"
#include "audio.h"
#include "carousel.h"
#include "cat.h"
#include "esp_random.h"
#include "gestures.h"
#include "settings.h"
#include "tokens.h"
#include "ui_util.h"

#define MAX_APPS   32
#define DEG_TO_RAD (3.14159265f / 180.0f)

static lv_obj_t *s_scr, *s_cat, *s_icon, *s_icon_next, *s_static;
static lv_obj_t *s_dots[CAROUSEL_MAX_DOTS];
static const app_t *s_apps[MAX_APPS];
static carousel_t s_car;
static gesture_track_t s_track;
static bool s_busy;
static uint8_t s_idle_level;
static lv_timer_t *s_react_timer;

static const app_t *current(void) { return s_apps[s_car.index]; }

static cat_state_t resting_state(void)
{
    return s_idle_level >= 2 ? CAT_SLEEPING : s_idle_level == 1 ? CAT_SLEEPY : current()->react;
}

static void load_visible_apps(void)
{
    uint32_t hidden = settings_hidden_apps();
    uint8_t n = 0;
    for (size_t i = 0; i < APP_COUNT && n < MAX_APPS; i++) {
        if (!(hidden & (1u << i))) {
            s_apps[n++] = APPS[i];
        }
    }
    if (n == 0) { /* never show an empty menu */
        for (size_t i = 0; i < APP_COUNT && n < MAX_APPS; i++) {
            s_apps[n++] = APPS[i];
        }
    }
    uint8_t keep = s_car.index;
    carousel_init(&s_car, n);
    s_car.index = keep < n ? keep : 0;
}

static void layout_dots(void)
{
    dot_window_t w = carousel_dot_window(&s_car);
    for (uint8_t k = 0; k < CAROUSEL_MAX_DOTS; k++) {
        lv_obj_t *d = s_dots[k];
        if (k >= w.n) {
            ui_set_hidden(d, true);
            continue;
        }
        uint8_t i = (uint8_t)(w.first + k);
        dot_kind_t kind = carousel_dot_kind(&s_car, i);
        int32_t size = kind == DOT_ACTIVE ? MENU_DOT_ACTIVE : kind == DOT_EDGE ? MENU_DOT_EDGE : MENU_DOT_IDLE;
        float kk = (float)k - (float)(w.n - 1) / 2.0f;
        float a = (90.0f - kk * MENU_DOT_STEP_DEG) * DEG_TO_RAD;
        int32_t cx = SCREEN_CENTER + (int32_t)lroundf(MENU_DOT_RADIUS * cosf(a));
        int32_t cy = SCREEN_CENTER + (int32_t)lroundf(MENU_DOT_RADIUS * sinf(a));
        lv_obj_set_size(d, size, size);
        lv_obj_set_pos(d, cx - size / 2, cy - size / 2);
        lv_obj_set_style_bg_color(d, kind == DOT_ACTIVE ? lv_color_hex(s_apps[i]->color) : lv_color_white(), 0);
        lv_obj_set_style_bg_opa(d, kind == DOT_ACTIVE ? LV_OPA_COVER : MENU_DOT_IDLE_OPA, 0);
        ui_set_hidden(d, false);
    }
}

static void react_later(lv_timer_t *t)
{
    (void)t;
    s_react_timer = NULL;
    cat_set_state(s_cat, resting_state());
}

static void say_name(bool with_whoosh)
{
    audio_play(with_whoosh ? current()->swipe_sound : current()->name_sound);
    cat_set_state(s_cat, CAT_TALKING);
    if (s_react_timer) {
        lv_timer_delete(s_react_timer);
    }
    s_react_timer = lv_timer_create(react_later, TALK_AFTER_NAME_MS, NULL);
    lv_timer_set_repeat_count(s_react_timer, 1);
}

static void set_scale(void *img, int32_t v) { lv_image_set_scale(img, (uint32_t)v); }
static void set_opa(void *obj, int32_t v) { lv_obj_set_style_opa(obj, (lv_opa_t)v, 0); }

static void run_anim(void *var, lv_anim_exec_xcb_t exec, int32_t from, int32_t to, uint32_t ms,
                     lv_anim_path_cb_t path, lv_anim_completed_cb_t done)
{
    lv_anim_t a;
    lv_anim_init(&a);
    lv_anim_set_var(&a, var);
    lv_anim_set_exec_cb(&a, exec);
    lv_anim_set_values(&a, from, to);
    lv_anim_set_duration(&a, ms);
    lv_anim_set_path_cb(&a, path);
    if (done) {
        lv_anim_set_completed_cb(&a, done);
    }
    lv_anim_start(&a);
}

static void slide_done(lv_anim_t *a)
{
    (void)a;
    ui_set_hidden(s_icon_next, true);
    run_anim(s_icon, set_scale, ICON_SCALE_SETTLE_FROM, LV_SCALE_NONE, ANIM_SETTLE_MS, lv_anim_path_overshoot, NULL);
    s_busy = false;
}

static void go(int8_t dir)
{
    if (s_car.count < 2) {
        say_name(false);
        return;
    }
    s_busy = true;
    carousel_step(&s_car, dir);
    lv_obj_t *out = s_icon, *in = s_icon_next;
    lv_image_set_src(in, assets_image(current()->icon));
    lv_image_set_scale(in, LV_SCALE_NONE);
    lv_obj_set_style_opa(in, LV_OPA_COVER, 0);
    lv_obj_set_x(in, MENU_ICON_X + dir * SCREEN_SIZE);
    ui_set_hidden(in, false);
    run_anim(out, (lv_anim_exec_xcb_t)lv_obj_set_x, MENU_ICON_X, MENU_ICON_X - dir * SCREEN_SIZE, ANIM_SWIPE_MS,
             lv_anim_path_ease_out, NULL);
    run_anim(in, (lv_anim_exec_xcb_t)lv_obj_set_x, MENU_ICON_X + dir * SCREEN_SIZE, MENU_ICON_X, ANIM_SWIPE_MS,
             lv_anim_path_ease_out, slide_done);
    s_icon = in;
    s_icon_next = out;
    layout_dots();
    say_name(true);
}

static void open_done(lv_anim_t *a)
{
    (void)a;
    app_manager_open(current());
}

static void open_current(void)
{
    s_busy = true;
    audio_play(SND_OPEN);
    run_anim(s_icon, set_scale, LV_SCALE_NONE, ICON_SCALE_OPEN, ANIM_OPEN_ZOOM_MS, lv_anim_path_ease_in, open_done);
    run_anim(s_icon, set_opa, LV_OPA_COVER, LV_OPA_TRANSP, ANIM_OPEN_ZOOM_MS, lv_anim_path_ease_in, NULL);
}

static bool in_circle(lv_point_t p, int32_t cx, int32_t cy, int32_t r)
{
    int32_t dx = p.x - cx, dy = p.y - cy;
    return dx * dx + dy * dy <= r * r;
}

static bool in_rect(lv_point_t p, int32_t x, int32_t y, int32_t w, int32_t h)
{
    return p.x >= x && p.x < x + w && p.y >= y && p.y < y + h;
}

static void on_release(gesture_kind_t g, lv_point_t p)
{
    if (s_busy) {
        return;
    }
    if (g == GESTURE_SWIPE_LEFT) {
        go(+1);
    } else if (g == GESTURE_SWIPE_RIGHT) {
        go(-1);
    } else if (g == GESTURE_TAP) {
        if (in_circle(p, MENU_ICON_CX, MENU_ICON_CY, MENU_ICON_R)) {
            open_current();
        } else if (in_circle(p, MENU_CAT_CX, MENU_CAT_CY, MENU_CAT_R)) {
            say_name(false);
        } else if (in_rect(p, MENU_ZONE_LEFT_X, MENU_ZONE_Y, MENU_ZONE_W, MENU_ZONE_H)) {
            go(-1);
        } else if (in_rect(p, MENU_ZONE_RIGHT_X, MENU_ZONE_Y, MENU_ZONE_W, MENU_ZONE_H)) {
            go(+1);
        }
    }
}

static void screen_event(lv_event_t *e)
{
    lv_indev_t *indev = lv_indev_active();
    if (!indev) {
        return;
    }
    lv_point_t p;
    lv_indev_get_point(indev, &p);
    uint32_t now = lv_tick_get();
    switch (lv_event_get_code(e)) {
    case LV_EVENT_PRESSED: gesture_begin(&s_track, (int16_t)p.x, (int16_t)p.y, now); break;
    case LV_EVENT_PRESSING: gesture_move(&s_track, (int16_t)p.x, (int16_t)p.y); break;
    case LV_EVENT_RELEASED: on_release(gesture_end(&s_track, (int16_t)p.x, (int16_t)p.y, now), p); break;
    default: break;
    }
}

static void chevron(const lv_point_precise_t *points)
{
    lv_obj_t *l = lv_line_create(s_static);
    lv_line_set_points(l, points, 3);
    lv_obj_remove_flag(l, LV_OBJ_FLAG_CLICKABLE);
    lv_obj_set_style_line_width(l, 7, 0);
    lv_obj_set_style_line_color(l, lv_color_white(), 0);
    lv_obj_set_style_line_opa(l, STATIC_OPA, 0);
    lv_obj_set_style_line_rounded(l, true, 0);
}

void launcher_create(void)
{
    s_scr = ui_screen();
    lv_obj_add_event_cb(s_scr, screen_event, LV_EVENT_PRESSED, NULL);
    lv_obj_add_event_cb(s_scr, screen_event, LV_EVENT_PRESSING, NULL);
    lv_obj_add_event_cb(s_scr, screen_event, LV_EVENT_RELEASED, NULL);
    load_visible_apps();

    s_cat = cat_create(s_scr, CAT_SCALE_M);
    cat_set_origin(s_cat, MENU_CAT_ORIGIN_X, MENU_CAT_ORIGIN_Y);

    s_icon_next = ui_image(s_scr, current()->icon, MENU_ICON_X, MENU_ICON_Y);
    ui_set_hidden(s_icon_next, true);
    s_icon = ui_image(s_scr, current()->icon, MENU_ICON_X, MENU_ICON_Y);
    lv_image_set_pivot(s_icon, MENU_ICON_SIZE / 2, MENU_ICON_SIZE / 2);
    lv_image_set_pivot(s_icon_next, MENU_ICON_SIZE / 2, MENU_ICON_SIZE / 2);

    char paw[48];
    cat_part_asset(paw, sizeof(paw), CAT_SCALE_M, "paw");
    const lv_image_dsc_t *pd = assets_image(paw);
    ui_image(s_scr, paw, MENU_PAW_A_CX - pd->header.w / 2, MENU_PAW_CY - pd->header.h / 2);
    ui_image(s_scr, paw, MENU_PAW_B_CX - pd->header.w / 2, MENU_PAW_CY - pd->header.h / 2);

    s_static = ui_plain(s_scr); /* chevrons, dots and hint shift together against burn-in */
    lv_obj_set_size(s_static, SCREEN_SIZE, SCREEN_SIZE);
    static const lv_point_precise_t CHEVRON_L[] = {{54, 238}, {36, 262}, {54, 286}};
    static const lv_point_precise_t CHEVRON_R[] = {{412, 238}, {430, 262}, {412, 286}};
    chevron(CHEVRON_L);
    chevron(CHEVRON_R);
    for (int i = 0; i < CAROUSEL_MAX_DOTS; i++) {
        s_dots[i] = ui_circle(s_static, 0, 0, MENU_DOT_IDLE, 0xFFFFFF);
    }
    float a = HOME_HINT_ANGLE_DEG * DEG_TO_RAD;
    lv_obj_t *hint = ui_image(s_static, "ui/paw_hint",
                              SCREEN_CENTER + (int32_t)lroundf(HOME_HINT_RADIUS * cosf(a)) - 12,
                              SCREEN_CENTER + (int32_t)lroundf(HOME_HINT_RADIUS * sinf(a)) - 12);
    lv_obj_set_style_image_opa(hint, STATIC_OPA, 0);
    layout_dots();
    cat_set_state(s_cat, current()->react);
}

void launcher_show(void)
{
    load_visible_apps();
    lv_anim_delete(s_icon, NULL);
    lv_image_set_src(s_icon, assets_image(current()->icon));
    lv_image_set_scale(s_icon, LV_SCALE_NONE);
    lv_obj_set_style_opa(s_icon, LV_OPA_COVER, 0);
    lv_obj_set_x(s_icon, MENU_ICON_X);
    layout_dots();
    cat_set_state(s_cat, resting_state());
    s_busy = false;
    if (lv_screen_active() != s_scr) {
        lv_screen_load_anim(s_scr, LV_SCR_LOAD_ANIM_FADE_IN, ANIM_HOME_MS, 0, true);
    }
}

void launcher_home_pressed(void) { say_name(false); }

void launcher_set_idle_level(uint8_t level)
{
    s_idle_level = level;
    if (!s_react_timer) {
        cat_set_state(s_cat, resting_state());
    }
}

    lv_obj_set_pos(s_static, (int32_t)(esp_random() % span) - BURN_SHIFT_PX,
                   (int32_t)(esp_random() % span) - BURN_SHIFT_PX);
}
```

**Idle rules** (from the design's burn-in section):

| Where | After | What happens |
| --- | --- | --- |
| Menu | 20 s | Dims to 35 % over 600 ms; the cat turns sleepy |
| Menu | 60 s | The cat sleeps |
| Menu | 120 s | The panel goes dark |
| Inside an app | 60 s without touch | Returns to the menu |

```c
#include "idle.h"
#include "app_manager.h"
#include "display.h"
#include "launcher.h"
#include "tokens.h"
#include "ui_util.h"

#define IDLE_TICK_MS 500

static uint8_t s_level;     /* 0 awake, 1 dim, 2 sleeping, 3 off */
static bool s_forced_off;   /* Power button: stays dark until a touch or a button */
static lv_obj_t *s_catcher; /* swallows the touch that wakes the screen */
static uint32_t s_last_shift;
static int s_anim_var; /* lv_anim needs a non-NULL var to identify the brightness fade */

static void set_brightness(void *var, int32_t v)
{
    (void)var;
    display_set_brightness((uint8_t)v);
}

static void fade_to(uint8_t pct, uint32_t ms)
{
    lv_anim_delete(&s_anim_var, set_brightness);
    if (ms == 0) {
        display_set_brightness(pct);
        return;
    }
    lv_anim_t a;
    lv_anim_init(&a);
    lv_anim_set_var(&a, &s_anim_var);
    lv_anim_set_exec_cb(&a, set_brightness);
    lv_anim_set_values(&a, display_brightness(), pct);
    lv_anim_set_duration(&a, ms);
    lv_anim_start(&a);
}

static void catcher_event(lv_event_t *e)
{
    (void)e;
    idle_wake();
}

static void show_catcher(bool show)
{
    if (show && !s_catcher) {
        s_catcher = ui_plain(lv_layer_top());
        lv_obj_set_size(s_catcher, SCREEN_SIZE, SCREEN_SIZE);
        lv_obj_add_flag(s_catcher, LV_OBJ_FLAG_CLICKABLE);
        lv_obj_add_event_cb(s_catcher, catcher_event, LV_EVENT_RELEASED, NULL);
    } else if (!show && s_catcher) {
        lv_obj_delete_async(s_catcher);
        s_catcher = NULL;
    }
}

static void apply_level(uint8_t level)
{
    if (level == s_level) {
        return;
    }
    s_level = level;
    show_catcher(level > 0);
    if (level == 0) {
        fade_to(BRIGHTNESS_FULL, 0);
    } else if (level == 1) {
        fade_to(IDLE_DIM_PCT, ANIM_DIM_MS);
    } else if (level == 3) {
        fade_to(0, 0);
    }
    if (!app_manager_current()) {
        launcher_set_idle_level(level);
    }
}

void idle_wake(void)
{
    s_forced_off = false;
    lv_display_trigger_activity(NULL);
    apply_level(0);
}

bool idle_wake_if_asleep(void)
{
    if (s_level == 0) {
        return false;
    }
    idle_wake();
    return true;
}

void idle_power_toggle(void)
{
    if (s_level == 3) {
        idle_wake();
    } else {
        s_forced_off = true;
        apply_level(3);
    }
}

uint8_t idle_level(void) { return s_level; }

static void tick(lv_timer_t *t)
{
    (void)t;
    uint32_t inactive = lv_display_get_inactive_time(NULL);
    if (app_manager_current()) {
        if (inactive >= IDLE_APP_HOME_MS) {
            app_manager_home();
        }
        return;
    }
    if (!s_forced_off) {
        uint8_t level = inactive >= IDLE_OFF_MS     ? 3
                        : inactive >= IDLE_SLEEP_MS ? 2
                        : inactive >= IDLE_DIM_MS   ? 1
                                                    : 0;
        if (level > s_level) {
            apply_level(level); /* only escalate here; waking happens on touch or a button */
        }
    }
    if (lv_tick_elaps(s_last_shift) >= BURN_SHIFT_MS) {
        s_last_shift = lv_tick_get();
        launcher_burn_in_shift();
    }
}

void idle_init(void)
{
    s_last_shift = lv_tick_get();
    lv_timer_create(tick, IDLE_TICK_MS, NULL);
}
```

```c
#include <stdint.h>
#include "app.h"
#include "assets.h"
#include "audio.h"
#include "cat.h"
#include "display.h"
#include "envelope.h"
#include "esp_heap_caps.h"
#include "tokens.h"
#include "ui_util.h"
#include "voice_fx.h"

typedef enum { V_IDLE, V_LISTEN, V_PLAY } vstate_t;

static const uint32_t ACCENT[VOICE_COUNT] = {COLOR_COSTUME_MOUSE, COLOR_COSTUME_LION, COLOR_COSTUME_ROBOT,
                                             COLOR_COSTUME_CAVE};
static const cat_costume_t COSTUME[VOICE_COUNT] = {CAT_COSTUME_MOUSE, CAT_COSTUME_LION, CAT_COSTUME_ROBOT,
                                                   CAT_COSTUME_MINER};
static const sound_id_t STING[VOICE_COUNT] = {SND_COSTUME_MOUSE, SND_COSTUME_LION, SND_COSTUME_ROBOT,
                                              SND_COSTUME_CAVE};
/* Playback waves: two arcs on each side of the cat (lv_arc angles: 0 = 3 o'clock, clockwise). */
static const struct {
    int16_t r, start, end;
} WAVES[4] = {{84, 330, 30}, {110, 325, 35}, {84, 150, 210}, {110, 145, 215}};

static vstate_t s_state;
static voice_t s_voice;
static uint32_t s_session; /* 0 while the app is closed; read by audio callbacks under the LVGL lock */
static lv_obj_t *s_cat, *s_cave, *s_mic, *s_glyph, *s_pulse, *s_countdown;
static lv_obj_t *s_ring[VOICES_RING_DOTS];
static lv_obj_t *s_waves[4];
static lv_timer_t *s_start_timer;
static uint16_t s_level_peak; /* audio task only */

static void set_opa(void *obj, int32_t v) { lv_obj_set_style_opa(obj, (lv_opa_t)v, 0); }
static void set_countdown(void *arc, int32_t v) { lv_arc_set_value(arc, (int16_t)v); }

static void loop_opa(lv_obj_t *obj, int32_t from, int32_t to, uint32_t ms)
{
    lv_anim_t a;
    lv_anim_init(&a);
    lv_anim_set_var(&a, obj);
    lv_anim_set_exec_cb(&a, set_opa);
    lv_anim_set_values(&a, from, to);
    lv_anim_set_duration(&a, ms);
    lv_anim_set_repeat_count(&a, LV_ANIM_REPEAT_INFINITE);
    lv_anim_start(&a);
}

static void show_state(vstate_t st)
{
    s_state = st;
    const bool listen = st == V_LISTEN, play = st == V_PLAY, off = !audio_available();
    uint32_t fill = off ? COLOR_MIC_OFF : listen ? COLOR_MIC_LISTEN : play ? COLOR_MIC_PLAY : COLOR_MIC_IDLE;
    lv_obj_set_style_bg_color(s_mic, lv_color_hex(fill), 0);
    lv_obj_set_style_border_color(s_mic, lv_color_hex(listen ? COLOR_MIC_RING_LISTEN : COLOR_MIC_RING), 0);
    lv_obj_set_style_image_opa(s_glyph, play || off ? 102 : LV_OPA_COVER, 0);

    lv_anim_delete(s_pulse, set_opa);
    lv_anim_delete(s_countdown, set_countdown);
    ui_set_hidden(s_pulse, !listen);
    ui_set_hidden(s_countdown, !listen);
    if (listen) {
        loop_opa(s_pulse, LV_OPA_COVER, LV_OPA_TRANSP, 1000);
        lv_arc_set_value(s_countdown, 1000);
        lv_anim_t a;
        lv_anim_init(&a);
        lv_anim_set_var(&a, s_countdown);
        lv_anim_set_exec_cb(&a, set_countdown);
        lv_anim_set_values(&a, 1000, 0);
        lv_anim_set_duration(&a, VOICES_RECORD_MAX_S * 1000 + VOICES_BLIP_LEAD_MS);
        lv_anim_start(&a);
    }
    for (int i = 0; i < 4; i++) {
        lv_anim_delete(s_waves[i], set_opa);
        lv_obj_set_style_opa(s_waves[i], LV_OPA_COVER, 0);
        ui_set_hidden(s_waves[i], !play);
        if (play) {
            loop_opa(s_waves[i], LV_OPA_COVER, 60, 600);

static void apply_costume(void)
{
    cat_set_costume(s_cat, COSTUME[s_voice]);
    lv_color_t accent = lv_color_hex(ACCENT[s_voice]);
    for (int i = 0; i < VOICES_RING_DOTS; i++) {
        lv_obj_set_style_bg_color(s_ring[i], accent, 0);
    }
    for (int i = 0; i < 4; i++) {

/* ---- audio-task callbacks: take the LVGL lock, then check the app is still open for this session ---- */

static bool lock_session(uint32_t session)
{
    if (!display_lock(-1)) {
        return false;
    }
    if (session == 0 || session != s_session) {
        display_unlock();
        return false;
    }
    return true;
}

static void on_recorded(uint32_t session, int16_t *pcm, size_t n, bool heard)
{
    if (!pcm || n == 0 || !heard) {
        heap_caps_free(pcm);
        if (lock_session(session)) {
            show_state(V_IDLE);
            audio_play(SND_MEOW); /* nothing heard: a meow instead of playing silence */
            display_unlock();
        }
        return;
    }
    const voice_t v = s_voice;
    size_t out_n = voice_fx_output_len(v, n, AUDIO_RATE_HZ);
    int16_t *out = heap_caps_malloc(out_n * sizeof(int16_t), MALLOC_CAP_SPIRAM);
    if (out) {
        out_n = voice_fx_apply(v, pcm, n, out, out_n, AUDIO_RATE_HZ);
    }
    heap_caps_free(pcm);
    if (!lock_session(session)) {
        heap_caps_free(out);
        return;
    }
    show_state(out ? V_PLAY : V_IDLE);
    s_level_calls = 0;
    s_level_peak = 0;
    display_unlock();
    if (out) {
        audio_play_pcm(session, out, out_n); /* ownership passes to the audio service */
    }
}

static void on_level(uint32_t session, uint16_t peak)
{
    if (peak > s_level_peak) {
        s_level_peak = peak;
    }
    if (++s_level_calls < 6) { /* 6 x 20 ms = 120 ms, about 8 fps */
        return;
    }
    uint8_t frame = envelope_mouth(s_level_peak);
    s_level_calls = 0;
    s_level_peak = 0;
    if (!display_lock(0)) { /* skip a mouth frame rather than stall the audio */
        return;
    }
    if (session == s_session && s_state == V_PLAY) {
        cat_set_mouth(s_cat, frame);
    }
    display_unlock();
}

static void on_done(uint32_t session)
{
    if (lock_session(session)) {
        if (s_state == V_PLAY) {
            show_state(V_IDLE);
        }
        display_unlock();
    }
}

static void start_recording(lv_timer_t *t)

    s_start_timer = NULL;

static void mic_tapped(lv_event_t *e)
{
    (void)e;
    if (!audio_available()) {
        return;
    }
    if (s_state == V_IDLE) {
        audio_play(SND_BLIP_UP);
        show_state(V_LISTEN);
        s_start_timer = lv_timer_create(start_recording, VOICES_BLIP_LEAD_MS, NULL);
        lv_timer_set_repeat_count(s_start_timer, 1);
    } else if (s_state == V_LISTEN) {
        if (s_start_timer) { /* tapped again before recording began */
            lv_timer_delete(s_start_timer);
            s_start_timer = NULL;
            show_state(V_IDLE);
        } else {
            audio_record_stop(s_session);
        }
    }
}

static void cat_tapped(lv_event_t *e)

    (void)e;

        return;

    s_voice = (voice_t)((s_voice + 1) % VOICE_COUNT);

}

static void build(lv_obj_t *scr)
```


`main/soak.c`:
```c
#include "sdkconfig.h"
#if CONFIG_CAT_DEV_SOAK
#include "soak.h"
#include <stdbool.h>
#include <stdlib.h>
#include "app.h"
#include "app_manager.h"
#include "display.h"
#include "esp_heap_caps.h"
#include "esp_log.h"
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"

#define SOAK_ROUNDS    50
#define SOAK_STEP_MS   500
#define SOAK_TOLERANCE 4096

static const char *TAG = "SOAK";

static void step(const app_t *app)
{
    display_lock(-1);
    lv_display_trigger_activity(NULL); /* keep idle dimming out of the measurement */
    app_manager_open(app);
    display_unlock();
    vTaskDelay(pdMS_TO_TICKS(SOAK_STEP_MS));
    display_lock(-1);
    app_manager_home();
    display_unlock();
    vTaskDelay(pdMS_TO_TICKS(SOAK_STEP_MS));
}

static void soak_task(void *arg)
{
    (void)arg;
    vTaskDelay(pdMS_TO_TICKS(6000)); /* boot animation */
    for (size_t i = 0; i < APP_COUNT; i++) {
        step(APPS[i]); /* warm-up: fills the image and sound caches */
    }
    size_t base_int = heap_caps_get_free_size(MALLOC_CAP_INTERNAL);
    size_t base_ps = heap_caps_get_free_size(MALLOC_CAP_SPIRAM);
    ESP_LOGI(TAG, "baseline internal=%u psram=%u", (unsigned)base_int, (unsigned)base_ps);
    for (int r = 0; r < SOAK_ROUNDS; r++) {
        for (size_t i = 0; i < APP_COUNT; i++) {
            step(APPS[i]);
        }
        if ((r + 1) % 10 == 0) {
            ESP_LOGI(TAG, "round %d internal=%u psram=%u", r + 1,
                     (unsigned)heap_caps_get_free_size(MALLOC_CAP_INTERNAL),
                     (unsigned)heap_caps_get_free_size(MALLOC_CAP_SPIRAM));
        }
    }
    vTaskDelay(pdMS_TO_TICKS(1000));
    long d_int = (long)heap_caps_get_free_size(MALLOC_CAP_INTERNAL) - (long)base_int;
    long d_ps = (long)heap_caps_get_free_size(MALLOC_CAP_SPIRAM) - (long)base_ps;
    bool pass = labs(d_int) <= SOAK_TOLERANCE && labs(d_ps) <= SOAK_TOLERANCE;
    ESP_LOGI(TAG, "%s: internal delta=%ld psram delta=%ld over %d rounds", pass ? "PASS" : "FAIL", d_int, d_ps,
             SOAK_ROUNDS);
    vTaskDelete(NULL);
}

void soak_start(void)
{
    xTaskCreatePinnedToCore(soak_task, "soak", 4096, NULL, 3, NULL, 0);
}
#endif
```
